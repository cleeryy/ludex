# Assets

Everything visual the repository publishes lives here. Three kinds of files, three rules:

| Path | What it is | Source |
|---|---|---|
| [`banner.svg`](banner.svg) | README hero banner, 1200×420, vector | Hand-written SVG using the app's wordmark geometry and the Midnight palette (`apps/web/src/theme/themes.json`) |
| [`social-preview.svg`](social-preview.svg) → [`social-preview.png`](social-preview.png) | GitHub social preview, 1280×640 | Same SVG, rasterized by the screenshot pipeline |
| [`screenshots/`](screenshots/) | Product screenshots for README and docs | `pnpm screenshots` — see [`screenshots/README.md`](screenshots/README.md) |
| `desktop-first-run.png` | Desktop first-run wizard, referenced by the README | Captured from the Tauri app; refresh with the desktop release that changes the wizard |

## Rules

- **No invented brand.** The wordmark, the signal-yellow full stop and the cover plates are the
  app's own geometry (`apps/web/src/components/brand.tsx`, `docs/assets/banner.svg`). Do not
  draw a new logo here; if the wordmark changes, update these files from it.
- **Every image is reproducible.** If it cannot be regenerated by a command in this repository,
  it does not belong in `docs/assets`.
- **Budgets.** Screenshots ≤ 300 KB, mobile ≤ 120 KB, other artwork ≤ 400 KB, whole set < 5 MB.
  `node scripts/check-assets.mjs` enforces them, and also fails when a Markdown file points at a
  file that no longer exists.
- **Alt text.** Every image reference carries a description of what is visible, not a filename.

## Social preview

GitHub does not read `social-preview.svg`; the repository setting needs a PNG:

```bash
scripts/screenshots.sh --only social   # or a full run
```

Then set it once in **Settings → General → Social preview** (1280×640 is what GitHub expects).
[`../REPO.md`](../REPO.md) lists the other repository settings that are not stored in git.
