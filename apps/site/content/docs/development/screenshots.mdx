Every image on this page is captured from the shipped web UI running the built-in demo
library — no mockups, no roadmap screens. The README uses a subset; the rest are here for
docs, issues and release notes.

The pipeline and the capture rules are documented in
[`assets/screenshots/README.md`](assets/screenshots/README.md); the machine-readable record of
the last run (version, commit, date, viewport, theme) is
[`assets/screenshots/manifest.json`](assets/screenshots/manifest.json).

### Console mode

Console mode is the ten-foot shell that Sunshine publishes as a single `Ludex` app. It is
the Cabinet: warm charcoal, matte panels, one lit game, signal yellow as the only chromatic
event. Three compositions share the room, the navigation and the sound language: **Stage**,
**Wall** and **List**.

![Console Stage: the selected game on a warm charcoal stage, one rail of covers and the system band](/images/screenshots/readme/console-stage.png)

![Console Wall: the library as a grid of covers under shelf chips](/images/screenshots/readme/console-wall.png)

The 720p, 1080p and 4K captures, plus a 5 % overscan crop of each, live in
`docs/assets/screenshots/console/`; `manifest.json` there records the safe-area
measurements.
